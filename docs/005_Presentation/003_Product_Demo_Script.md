# NSSMS — Product Demonstration Script

## Scenario
Demonstrate the complete journey from administrative setup to public verification.

### Step 1 — Dashboard
Show the administrative dashboard and authorized scope.

### Step 2 — Season
Create a draft season, submit it, review it, approve it, and activate it.

### Step 3 — Competition
Create a competition under the active season.

### Step 4 — Participant
Create or select a participant associated with an institution.

### Step 5 — License
Create and approve a digital license.

### Step 6 — QR
Open the verification experience.

### Step 7 — Public Portal
Demonstrate the public verification result without exposing private data.

### Step 8 — Audit
Return to the administration portal and show the recorded operations.

## Demonstration Objective
Prove the core project principles:
**regulation → controlled workflow → digital record → QR verification → audit → historical preservation.**
