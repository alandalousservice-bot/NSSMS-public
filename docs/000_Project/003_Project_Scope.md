# NSSMS — Project Scope

## In Scope
- Seasons.
- Competitions.
- Digital sports licenses.
- QR verification.
- Audit.
- Public portal.
- Administrative dashboards.
- Business and system requirements.
- Database and UI design.
- Security and API planning.
- Testing and deployment documentation.

## Functional Scope
The functional scope will be decomposed into:
1. Identity and access.
2. Organizational administration.
3. Season management.
4. Competition management.
5. Participant and school records.
6. Digital licensing.
7. QR verification.
8. Results and reporting.
9. Audit.
10. Public information.

These modules are an initial decomposition and require business validation.

## Out of Scope for the Baseline
No specific external integration, technology, hosting provider, or detailed regulatory workflow is considered final until approved.

## Scope Control
Every new requirement should identify:
- Business reason.
- Affected module.
- Affected data.
- Security impact.
- UI impact.
- Testing impact.
- Approval status.
