# NSSMS — Master Project Specification

**Status:** WORK IN PROGRESS (WIP)

## Vision
إنشاء النظام الوطني لتسيير الرياضة المدرسية في الجزائر كمنصة حكومية رسمية.

## Project Pillars
1. تطبيق اللوائح الرسمية.
2. هوية بصرية حكومية جزائرية.
3. إدارة المواسم والمنافسات.
4. إجازات رقمية مع QR.
5. سجل تدقيق Audit.
6. عدم الحذف النهائي.
7. بوابة عامة ولوحات إدارة.

## Final Specification Coverage
The master specification is intended to evolve into a comprehensive specification covering:
- Analysis.
- Requirements.
- Database.
- User interfaces.
- Security.
- API.
- Implementation plan.

## Source-of-Truth Rule
When a future design decision is not explicitly defined by the master specification, it must be recorded as a decision, assumption, or open question and approved before becoming a hard requirement.
