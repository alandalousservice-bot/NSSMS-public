# NSSMS — Roles and Permissions

## Initial Role Categories
- System Administrator.
- National Administrator.
- Regional/Wilaya Administrator.
- Institution/School Operator.
- Competition Official.
- Public User.

These are categories only and must be validated against the official organizational structure.

## Permission Model
Permissions should be expressed as controlled actions, for example:
- View.
- Create.
- Edit.
- Submit.
- Approve.
- Publish.
- Verify.
- Archive.
- Audit View.

## Security Rule
No role should receive permissions merely because it exists; permissions must be tied to documented business responsibilities.
