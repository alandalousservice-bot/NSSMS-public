# NSSMS — Data Lifecycle

## General Lifecycle

```text
Create → Validate → Approve → Active → Close → Archive
```

## Non-Destructive Rule
Permanent deletion must not be used for governed official records.

## Deactivation
Where a record should no longer be operational:
- Change status.
- Record the reason where required.
- Preserve history.
- Maintain auditability.

## Archive
Archive should preserve:
- Identity.
- Historical relationships.
- Important timestamps.
- Audit history.
