# NSSMS — Database Design

## Initial Entities
- User
- Role
- Permission
- Organization
- Educational Institution
- Participant
- Season
- Competition
- Sports License
- QR Verification
- Result
- Audit Log

## Data Principles
- Referential integrity.
- Historical preservation.
- Controlled lifecycle.
- Auditability.
- Validation at application and database levels where appropriate.

## Deletion Policy
Official governed records must not be permanently deleted. The exact archival and deactivation model requires approval.
