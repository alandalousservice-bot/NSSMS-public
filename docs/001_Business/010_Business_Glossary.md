# NSSMS — Business Glossary

| Term | Definition |
|---|---|
| NSSMS | National School Sports Management System |
| Season | A defined sports period used to organize school-sports activities |
| Competition | An organized school-sports event or competition managed by NSSMS |
| Participant | A person participating in school-sports activities |
| Institution | An educational organization represented in NSSMS |
| Sports License | A digital representation authorizing/identifying a participant according to approved rules |
| QR Verification | Verification process using a QR code associated with a digital license |
| Audit | Historical record of important system operations |
| Public Portal | Area accessible to public users |
| Administrative Portal | Controlled area for authorized users |
| Archive | Historical state retained for records no longer operational |
| Approval | A controlled business action that authorizes a record to progress |
| Organizational Scope | The administrative boundary within which a user can operate |

Definitions are subject to official terminology validation.
