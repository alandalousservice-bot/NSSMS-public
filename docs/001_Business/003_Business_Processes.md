# NSSMS — Business Processes

## Process 1 — Season Management
```text
Create → Review → Approve → Open → Active → Close → Archive
```
**Status:** Proposed lifecycle; requires regulatory validation.

## Process 2 — Competition Management
```text
Draft → Review → Approve → Registration → Competition → Results → Close → Archive
```
**Status:** Proposed lifecycle; requires validation.

## Process 3 — Digital License
```text
Application → Validation → Approval → Issue → Verify → Renew/Expire
```
**Status:** Proposed lifecycle; exact rules TBD.

## Process 4 — Public Publication
```text
Internal Record → Validation → Approval → Public Publication
```

## Process 5 — Audit
```text
Protected Operation → Audit Event → Historical Record
```

No workflow becomes an official business rule until approved.
